The Ornstein–Uhlenbeck Process

\(M\) independent paths are simulated with the Euler–Maruyama scheme applied to \(dX_t = -\theta(X_t - \mu)\,dt + \sigma\,dW_t\): at each timestep, every path moves by a deterministic pull back toward \(\mu\) plus a fresh Gaussian random kick, drawn independently per path, per step.

On screen, each path's last 260 steps are traced left to right as it happens — a live scope, not a replay. At the leading edge, the current value of every path is read off and binned into the histogram on the right, compared against the theoretical stationary density \(\mathcal{N}\!\left(\mu,\ \sigma^2/2\theta\right)\) (gold curve). In Live mode the histogram is a fresh snapshot every frame; in Accumulate mode it's a running density estimate built up over time, which is why it starts noisy and sharpens as samples accumulate.
